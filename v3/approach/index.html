Approach3つの事業が循環し、価値創造を加速する

B supplyは、コンサルティング・投資・投資先の経営（バリューアップ）の3つの事業を循環させ、日本の中小企業が持つ伝統・文化・技術をグローバルへ届けます。

3つの事業が循環し、価値創造を加速する

  1. Consulting

    コンサルティング事業

    参謀役として経営支援

    クライアントの課題を解き、戦略を描き、実行まで支える。その現場で得た知見が、自社で行う事業投資・承継と経営の判断力を磨いていく。

    View More

  2. Investment

    事業投資・承継事業

    中小企業への投資

    日本の産業を支える技術、文化、顧客基盤を持つ中小企業に投資する。自らの手で、より事業価値を磨き、次の世代へ続く成長をつくっていく。

    View More

  3. Value Up

    革製造事業

    事業承継先の経営／再生

    承継した事業に入り込み、現場とともに成長の打ち手を実行する。自ら経営に向き合う経験が、B supplyのコンサルティングをより実践的なものにする。

    View More

  4. Track Record

    東京・墨田区の革製造工房を事業承継

    第1号案件 ｜ 2026年

    1966年創業、60年にわたり一流ブランドの革製品を作り続けてきた工房を承継。職人の技術と雇用をそのまま受け継ぎ、B supplyの営業力とデジタル基盤を掛け合わせて、次の成長を実装しています。
